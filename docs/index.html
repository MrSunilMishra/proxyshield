Legal & Privacy Transparency Policy

⚠️ Mandatory Transparency Statement (Section J)

"ProxyShield uses publicly available third-party proxy services for educational and authorized network security auditing. The operator's direct public IP is not intentionally used for target requests in strict proxy-only mode. Public proxy operators may observe, inspect or log traffic. ProxyShield does not guarantee anonymity, privacy or proxy security. All testing must be conducted against authorized targets."

ProxyShield is strictly designed for defensive network diagnostics and educational security research. It must NEVER be used to conduct DDoS attacks, flood server infrastructure, or evade security controls.

How to Install (Isolated with `uv`)

We recommend uv to install dependencies inside a local .venv without modifying your global system Python.

bash (Terminal) 
# 1. Create isolated environment with uv
uv venv .venv
source .venv/bin/activate

# 2. Install ProxyShield & dependencies
uv pip install -e .[dev]

# 3. Verify installation
pxs -v
Termux (Android) 
# 1. Update Termux & install Python
pkg update && pkg install python git -y

# 2. Setup virtual environment
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e .

# 3. Run ProxyShield
pxs
PowerShell (Windows) 
# 1. Setup isolated venv with uv
uv venv .venv
.\.venv\Scripts\Activate.ps1

# 2. Install packages
uv pip install -e .[dev]

# 3. Run CLI
pxs
Command Prompt (CMD) 
REM 1. Setup isolated venv with uv
uv venv .venv
call .venv\Scripts\activate.bat

REM 2. Install packages
uv pip install -e .[dev]

REM 3. Run CLI
pxs

How to Run (`pxs` or `proxyshield`)

You can run commands using either the full name proxyshield or the ultra-fast short alias pxs:

bash 
# 1. Launch interactive startup menu
pxs
# (or: proxyshield)

# 2. View Global Help & All Available Commands (-h or --help)
pxs -h

# 3. View Version & Author Information (-v or --version)
pxs -v

pxs p (Proxy)

Query, filter, and benchmark free proxies from Geonode & ProxyScrape. Add -h for sub-options.

pxs a (Audit)

Conduct strict-proxy security audits against authorized target URLs with zero direct-IP fallback.

pxs b (Banner)

Generate CFonts-style ASCII banners with TrueColor gradients, shade, and shadow effects.

pxs c (Config)

Manage branding.txt with owner-only chmod 600 permissions.

How to Use with Target URLs & External Tools

ProxyShield provides two primary ways to work with URLs: auditing authorized web targets and consuming live proxy URLs in tools like curl or browsers.

1. Auditing an Authorized Target URL

Tests target response codes, latency, and firewall behavior strictly through verified proxies without exposing your real IP:

# Audit target URL across 10 verified proxies
pxs a -t "https://example.com"

# Customize delay (1.5s) & report name
pxs a -t "https://example.com" -d 1.5 -r audit_report

Generates audit_report.html, audit_report.json, and audit_report.csv.

2. Using Proxy URLs with `curl` or Scripts

Retrieve an instant working proxy URL and pipe it directly to network tools:

# Get single instant working proxy URL
pxs p r
# Output: socks5://120.220.197.198:59999

# Use the proxy URL with curl
curl -x $(pxs p r) https://api.ipify.org

Your real public IP remains completely masked by the proxy.

📊 How to Open and View Generated HTML Reports

After running an audit, open the generated HTML dashboard in your default browser:
• Windows: start audit_report.html
• macOS: open audit_report.html
• Linux: xdg-open audit_report.html

Step 3: Multi-Source Free Proxy Aggregator

ProxyShield integrates live proxy feeds from both Geonode API and ProxyScrape v4 API, deduplicating endpoints, benchmarking latency, and filtering by protocol and geography.

bash 
# 1. Fetch live proxies combining both Geonode & ProxyScrape
proxyshield proxy

# 2. Fetch exclusively from Geonode or ProxyScrape
proxyshield proxy fetch --source geonode --limit 20
proxyshield proxy fetch --source proxyscrape --limit 20

# 3. Filter by protocol (SOCKS5, HTTP, SOCKS4)
proxyshield proxy fetch --protocol socks5 --limit 15
proxyshield proxy fetch --protocol http --ssl

# 4. Filter by Country (e.g. US, DE, CN, ES) & Anonymity
proxyshield proxy fetch --country US --anonymity elite

# 5. Export results to .txt or .json
proxyshield proxy fetch --limit 50 --output proxies.txt
proxyshield proxy fetch --format json --output proxies.json

# 6. Concurrently diagnose live connectivity & latency
proxyshield proxy check --limit 15 --timeout 3

# 7. Grab a single instant working proxy
proxyshield proxy random --protocol socks5

Step 4: Strict-Proxy Security Auditing & Direct-IP Protection

Conduct controlled, low-rate HTTP security diagnostics against authorized targets strictly through public proxies. Automatic direct connection fallback is permanently disabled.

🛡️ Direct-IP Guard Mechanism (Section C)

Before testing any target, ProxyShield discovers the operator's actual public IP. If the proxy's observed exit IP unexpectedly matches the operator's IP, or if the proxy fails, the request is immediately aborted to prevent direct IP exposure.

bash 
# Audit authorized target through 10 verified proxies
proxyshield audit --target "https://example.com" --limit 10

# Audit with custom rate limit delay (1.5 seconds) and save reports
proxyshield audit --target "https://example.com" --delay 1.5 --report audit_results

Step 6: Configuration Management & Security

Configuration is stored at ~/.config/proxyshield/branding.txt with owner-only permissions (chmod 600 for file, chmod 700 for directory).

bash 
# Display active configuration
proxyshield config show

# Validate keys, color hex codes, and permission security
proxyshield config validate

# Edit in system editor ($EDITOR / nano / vim / notepad)
proxyshield config edit

# Verify & enforce strict 0600 file security
proxyshield config permissions --fix

# Reset to factory defaults (requests [y/N] confirmation)
proxyshield config reset
